# Почуйки · Розклад 2026–2027

Сайт розкладу уроків 5–9 класів Почуйківської філії Квітневого ліцею, І семестр.

Розклад відтворено з фотографії. Дзвінки збережено з попереднього сайту. Годинник, таймери та хвилина мовчання використовують спільний київський час.

Інструкція: [SCHEDULE_SETUP.md](SCHEDULE_SETUP.md).

```
npm run dev
npm test
npm run build
```

Сторонні залежності не потрібні.
