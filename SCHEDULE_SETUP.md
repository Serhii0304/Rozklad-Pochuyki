# Розклад Почуйківської філії · І семестр 2026–2027

Джерело уроків: фотографія «Розклад 2026-2027.jpg» зі шкільної папки. Відтворено всі клітинки 5–9 класів. Початкові класи вилучено; старі адреси перенаправляють на новий сайт.

## Редагування

Усі предмети, класи й дзвінки — у `schedule-config.js`. Кожний рядок має день, номер уроку та п’ять предметів у порядку 5, 6, 7, 8, 9 клас. Порожній рядок означає відсутність уроку.

Скорочення розгорнуто. «Музика» уніфіковано як «Музичне мистецтво». «Історія», «Природознавство», «Основи здоров’я» збережено за джерелом; назви навчальних курсів не підмінено припущеннями.

У фото підсумки для 6 класу (29,5) та 8 класу (24) не збігаються з заповненими клітинками (31 і 27 відповідно). Відтворено самі клітинки, без довільного вилучення уроків. Для решти класів: 5 — 32, 7 — 33, 9 — 35.

## Час і звук

`kyiv-clock.mjs` — спільний годинник Europe/Kyiv з літнім/зимовим часом, періодичною онлайн-звіркою і резервним часом пристрою. Без онлайн-звірки потрібен правильний системний час.

`time-core.mjs` — часові межі та стан уроків. `minute-of-silence.mjs` — відтворення о 09:00:00 включно до 09:01:00 виключно щодня, включно з вихідними. Пізній вхід використовує зміщення від 09:00; наприклад, 09:00:35 → 35-та секунда та ще 25 секунд. Використовується перша хвилина оригінального MP3; якщо його неможливо завантажити або він закороткий — локальний метроном.

Будь-який звичайний дотик/натискання клавіші готує AudioContext. Окреме підтвердження не обов’язкове. Кнопка показується під час хвилини, тільки якщо браузер заблокував звук. Автоматичний запуск без жодної взаємодії залежить від політики браузера. Сайт не може гарантувати звук на вимкненому або сплячому пристрої, у замороженій вкладці чи при системному вимкненні звуку. AudioBufferSourceNode планує завершення незалежно від частоти UI-таймера.

Між вкладками використовується Web Locks; для старих браузерів — резервна оренда через localStorage (best effort). Якщо обидва механізми недоступні, слід лишити одну вкладку.

## Запуск та перевірка

Потрібен Node.js. Сторонніх npm-залежностей немає.

- `npm run dev` — локальний перегляд на localhost:4173.
- `npm test` — перевірки меж уроків, часових поясів та аудіо.
- `npm run build` — перевірка синтаксису й імпортів, статичні файли до `build/`.

Кореневі файли сумісні з GitHub Pages, включно з адресою /Rozklad-Pochuyki/. Для Sites статичний каталог — `build`.

## Функції

Перегляд дня/тижня; вибір класу; посилання на тиждень класу; загальний та поденний фільтр предметів; виділення предмету натисканням; виділення поточного рядка; таймери; розклад дзвінків; друк дня, тижня, класу й дзвінків через браузер/PDF; клавіатурна навігація; адаптація до телефону та планшета. Друк класу за тиждень — компактна матриця.
