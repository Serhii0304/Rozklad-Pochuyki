# Розклад Почуйківської філії · І семестр 2026–2027

Джерело уроків: фотографія «Розклад 2026-2027.jpg» зі шкільної папки. Відтворено всі клітинки 5–9 класів. Початкові класи вилучено. Збережено звичні адреси: index.html — усі дні; class.html?class=9%20клас — тиждень класу; «Розклад дзвінків.html» — дзвінки. Адреси застарілих початкових класів перенаправляють на головну.

## Редагування

Усі предмети, класи й дзвінки — у `schedule-config.js`. Кожний рядок має день, номер уроку та п’ять предметів у порядку 5, 6, 7, 8, 9 клас. Порожній рядок означає відсутність уроку.

Скорочення розгорнуто. «Музика» уніфіковано як «Музичне мистецтво». «Історія», «Природознавство», «Основи здоров’я» збережено за джерелом; назви навчальних курсів не підмінено припущеннями.

У фото підсумки для 6 класу (29,5) та 8 класу (24) не збігаються з заповненими клітинками (31 і 27 відповідно). Відтворено самі клітинки, без довільного вилучення уроків. Для решти класів: 5 — 32, 7 — 33, 9 — 35.

## Час і звук

`kyiv-clock.mjs` — спільний годинник Europe/Kyiv з літнім/зимовим часом, періодичною онлайн-звіркою і резервним часом пристрою. Без онлайн-звірки потрібен правильний системний час.

`time-core.mjs` — часові межі та стан уроків. `minute-of-silence.mjs` — відтворення о 09:00:00 включно до 09:01:00 виключно щодня, включно з вихідними. Пізній вхід використовує зміщення від 09:00; наприклад, 09:00:35 → 35-та секунда та ще 25 секунд. Використовується перша хвилина оригінального MP3; якщо його неможливо завантажити або він закороткий — локальний метроном.

Будь-який звичайний дотик/натискання клавіші готує AudioContext. Окреме підтвердження не обов’язкове. Кнопка показується під час хвилини, тільки якщо браузер заблокував звук. Автоматичний запуск без жодної взаємодії залежить від політики браузера. Сайт не може гарантувати звук на вимкненому або сплячому пристрої, у замороженій вкладці чи при системному вимкненні звуку. AudioBufferSourceNode планує завершення незалежно від частоти UI-таймера.

Між вкладками використовується Web Locks; для старих браузерів — резервна оренда через localStorage (best effort). Якщо обидва механізми недоступні, слід лишити одну вкладку.

## Запуск та перевірка

Потрібен Node.js. Сторонніх npm-залежностей немає.

- `npm run dev` — локальний перегляд на localhost:4173.
- `npm test` — перевірки меж уроків, часових поясів та аудіо.
- `npm run build` — перевірка синтаксису й імпортів, статичні файли до `build/`.

Кореневі файли сумісні з GitHub Pages, включно з адресою /Rozklad-Pochuyki/. Для Sites статичний каталог — `build`.

## Функції

Перегляд дня/тижня; вибір класу; посилання на тиждень класу; загальний та поденний фільтр предметів; виділення предмету натисканням; виділення поточного рядка; таймери; розклад дзвінків; друк дня, тижня, класу й дзвінків через браузер/PDF; клавіатурна навігація; адаптація до телефону та планшета. Друк класу за тиждень — компактна матриця.

## Оформлення та збережена структура

Головна показує всі дні тижня, кнопки днів переходять до відповідної таблиці. Окремий клас одразу відкриває одну матрицю «7 уроків × 5 днів» як у старій версії; додатково доступний перегляд дня. Переходи між цими адресами всередині сайту зберігають аудіоконтекст, щоб навігація не обривала метроном. Пряме відкриття кожної адреси також працює.

Кольорові кнопки класів мають підсвічування та ефект натискання. Світла/темна тема спочатку враховує налаштування пристрою; ручний вибір зберігається локально під ключем pochuyki.theme. Джерела адаптованих відкритих стилів і ліцензії — THIRD_PARTY_NOTICES.md. Файл enhancements.css містить оформлення.

Фон school-background-2026.png згенеровано вбудованим ImageGen спеціально для сайту. Обидві теми використовують той самий фон без зміни кольорів або затемнювального шару. Темна тема змінює лише панелі, таблиці й елементи керування. Друк лишається світлим. Виділення предмета змінює лише збіги, без приглушення інших уроків.

25 автоматичних перевірок пройдено (включно з темами, матрицями класів і унікальністю значків). Окремо виконано DOM-перевірку запуску трьох сторінок, переходів усіх п’яти днів у двох режимах, виділення предметів, поточного/наступного уроку та збереження одного аудіоконтексту під час навігації.

26 авторських SVG у assets/subjects мають унікальні композиції без emoji та зовнішніх шрифтів. Відповідність предметам зберігається в subjectIcons. subject-icons.mjs додає їх до головної таблиці та матриці класу. Значки школи й дзвіночка в assets/ui згенеровані ImageGen і оптимізовані до 256 px із прозорим фоном.


## Виразне виділення

highlights.css визначає два окремі стани: вибраний предмет — фіолетова картка з анімованою світловою рамкою, знаком вибору та коротким ефектом значка; поточний урок — суцільний синьо-бірюзовий рядок, акцент на номері, позначка «Зараз» із плавним відблиском. Вибраний предмет залишається помітним усередині поточного рядка. Рух враховує prefers-reduced-motion; постійні рамки працюють і без CSS-масок. Решта таблиці не приглушується; фон не змінюється.

Візуальні орієнтири (переглянуто 07.09.2026): [Magic UI Border Beam](https://magicui.design/docs/components/border-beam), [Magic UI Shine Border](https://v3.magicui.design/docs/components/shine-border), [Aceternity Glowing Effect](https://ui.aceternity.com/components/glowing-effect). Реалізація CSS авторська, сторонні компоненти й залежності не додавалися.

Плаваюча кнопка «Нагору» з’являється після 360 px прокручування на всіх сторінках. Доступна з клавіатури, враховує безпечні поля смартфона та вимкнення руху. Після повернення фокус переходить на заголовок сторінки.
